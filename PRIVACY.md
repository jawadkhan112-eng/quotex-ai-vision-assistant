# PRIVACY POLICY & SCREEN CAPTURE DISCLOSURE

1. **User-Authorized Screen Capture**: Screen capture features utilize standard WebRTC `getDisplayMedia` browser dialogs. Screen sharing requires explicit user authorization every time.
2. **No Secret Recording**: The app never records in the background without visible active user indication.
3. **No Private Data Harvesting**: The application inspects chart price action only. It never reads or stores personal credentials, passwords, bank numbers, or personal identifying information.
4. **Local Data Ownership**: SQLite database and saved screenshot history reside locally on the user's system in `/data` and `/uploads`.
